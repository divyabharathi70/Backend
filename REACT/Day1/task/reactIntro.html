Task 1

React Basics

1. What is React?

React is a JavaScript library used to build interactive user interfaces, especially web applications. It uses reusable components to organize the UI.

2. Why do we use React?

React helps us build interactive and maintainable applications using components, declarative UI, and efficient update strategies.

3. Is React a library or framework?

React is a JavaScript library because it mainly focuses on the user interface layer.

4. Main features of React

  • Component-based architecture
  • JSX
  • Declarative UI
  • Reconciliation
  • Reusable components
  • One-way data flow
  • Hooks

5. What is a Single Page Application?

A Single Page Application loads one main HTML document and updates visible content without fully reloading the document for every navigation.

6. What is declarative UI?

Declarative UI means describing what the UI should look like for a particular state instead of manually writing every DOM operation.

Task 2

Components

1. What is a Component?

A component is an independent and reusable part of the user interface.

2. Why do we use Components?

Components divide a large UI into smaller parts, making the application easier to understand, maintain, and reuse.

3. What is a Functional Component?

A functional component is a JavaScript function that returns JSX. 

function Welcome() {
    return <h1>Welcome</h1>;
}

4. Component-Based Architecture

It means building an application by combining small, independent components.

5. What is a Component Tree?

A component tree represents the parent-child relationship between components.

6. Why should component names start with a capital letter?

React uses capitalization to distinguish custom components from normal HTML elements.

7. What is a reusable component?

A reusable component is written once and used in multiple places with different props. 

function Button({ text }) {
    return <button>{text}</button>;
}

<Button text="Login" />
<Button text="Register" />

Task 3

JSX

1. What is JSX?

JSX stands for JavaScript XML. It is a syntax extension that allows us to write HTML-like UI code inside JavaScript.

2. Why do we use JSX?

JSX makes UI code easier to read and allows JavaScript expressions to be inserted directly into the UI.

3. Is JSX HTML?

No. JSX is not HTML. It is transformed into JavaScript and follows React-specific rules.

4. JavaScript expressions inside JSX 

const name = "Divya";

return <h1>Hello {name}</h1>;

5. Why do we use className?

JSX uses className instead of class for CSS class attributes.

6. What is React Fragment?

A Fragment allows multiple elements to be returned without adding an unnecessary wrapper element to the DOM.

7. Important JSX Rules

  • Close all tags.
  • Use className instead of class.
  • Use curly braces for expressions.
  • Return one parent or Fragment.
  • Use keys when rendering lists.

Task 4

DOM, Virtual DOM & Reconciliation

1. What is DOM?

DOM stands for Document Object Model. It represents the HTML document as a tree.

2. What is Virtual DOM?

The Virtual DOM is an in-memory representation of the UI used in explaining React's update process.

3. Difference between DOM and Virtual DOM

DOM Virtual DOM
Browser's document representation. In-memory UI representation.
Managed through browser APIs. Used by React's rendering process.
Represents the actual document. Helps determine required updates.

4. What is Reconciliation?

Reconciliation is the process React uses to compare previous and new UI descriptions and determine necessary updates.

5. What is Diffing?

Diffing is the comparison process used to find differences between previous and new React element trees.

6. How does React identify changes?

React considers element types, props, positions, and keys while comparing UI.

7. Why is key important?

Keys provide stable identities for list items and help React track additions, removals, and changes.

1. What is Rendering?

Rendering is the process in which React runs a component to calculate its UI description.

2. What is Re-rendering?

Re-rendering means React runs a component again to calculate an updated UI description.

3. What causes a component to re-render?

  • State changes
  • Parent re-renders
  • Props change
  • Context changes

4. Does re-render mean the complete DOM is recreated?

No. A re-render calculates a new UI description. React compares it with the previous description and applies the required DOM changes.

5. What happens during reconciliation?

React compares the previous and new rendered results and determines which parts should be preserved, updated, inserted, or removed.

6. Relationship between Virtual DOM, Diffing and Reconciliation

React uses in-memory UI descriptions and comparison techniques during reconciliation to determine the necessary rendered updates.

7. Explain the React rendering process

First, I create a component and write JSX. React renders the component and creates a UI description. When state or props change, React calculates the updated description. It compares the previous and new descriptions and applies the required changes to the browser DOM.
